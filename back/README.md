Carcassonne for [boardgame-web-ts](https://github.com/HMHamster88/boardgame-web-ts)

Web based boardgame module for Carcassonne with multiplayer support.

To build:

Download and build [boardgame-web-ts](https://github.com/HMHamster88/boardgame-web-ts)

Create .env file:

```
GAMES_MODULES_PATH='<Path to boardgame-web-ts data dir>\games-modules' (Default: '../boardgame-web-ts/back/dev-data/games-modules')
```

```
npm install
npm run link-common
npm run build-all
```
